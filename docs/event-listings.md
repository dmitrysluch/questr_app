# Event listings

`EventListing` is a Questr-curated public event card, separate from a user-created adventure. Admins use the **Event listings** page to save a draft, publish or cancel it, and edit its source, organizer, time, city, venue and optional community topic. The venue is exactly one saved public Place or Google Maps URL with a display name. The source URL must use HTTPS. A community topic filters listings; it does not grant membership or restrict the card. Adventure community restrictions remain unchanged.

Active characters browse **Adventures → Events**, filter by city, local event date and community topic, and open the source or map. Cancelled and ended listings leave the current catalog; their direct URL remains an archive. **Gather a party** opens a prefilled adventure form with the listing's title, time and city. The host writes the party plan, chooses its language and private meeting details, then publishes through the normal `events.create` permission and budget. Opening or closing the form creates no adventure and spends no budget. Multiple adventures may refer to one listing; each keeps its own meeting point and membership.

The database link is `events.event_listing_id`. Admin edits increment `event_listings.revision`, write a full snapshot to `event_listing_versions`, and add a `permission_audit` record. The listing stores `last_checked_at` after each admin save. Public listing responses never include adventure private meeting details. Source and Maps URLs are only validated and opened by the browser; the server does not fetch them.
